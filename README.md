# Systems Analysis and Development (ADS) - Coursework & Projects

> A comprehensive repository containing practical projects, coursework, and exercises developed during the Systems Analysis and Development (Análise e Desenvolvimento de Sistemas) degree program at Faculdade Descomplica. It covers topics from core programming logic and frontend design to full-stack web applications and DevOps pipelines.

[![Access: GitHub](https://img.shields.io/badge/-Access:%20GitHub-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/vitoriapguimaraes/ADS-code)

## Key Features

- **Structured Academic Modules:** Organized coursework covering Frontend Development, Dynamic Web Scripting, Object-Oriented Programming, and DevOps practices.
- **Full-Stack Application Development:** Real-world hands-on project (`MediApp`) implementing a medical consultation management system with Node.js backend and modern frontend layout.
- **DevOps & Infrastructure:** Hands-on experience with Docker containerization, Docker Compose setups, and CI/CD workflow automation (`M4A-DevopsI`).
- **Core Programming Logic:** Practice in programming logic and algorithms using Portugol and Java.

## Getting Started

### Prerequisites

- **Node.js** (v18+ recommended) & npm
- **Java Development Kit (JDK)** 17+
- **Docker** & **Docker Compose**
- **Git**

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vitoriapguimaraes/ADS-code.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ADS-code
   ```

### Execution

- **MediApp (Module M2A):**
  - **Backend:**

    ```bash
    cd M2A-ProgramacaoII/MediApp/src
    node index.js
    ```

  - **Frontend:**

    ```bash
    cd M2A-ProgramacaoII/MediApp/medi-app
    npm install
    npm run dev
    ```

- **DevOps Container Setups (Module M4A):**

  ```bash
  cd M4A-DevopsI/docker
  docker-compose up -d
  ```

## How to Use

1. **Course Modules Exploration:** Navigate through `M1A-*`, `M1B-*`, `M2A-*`, and `M4A-*` directories to access exercise files, lesson scripts, and diagrams.
2. **Testing Full-Stack Features:** Launch the `MediApp` backend server and frontend client simultaneously to test consultation scheduling, prescription management, and doctor/patient registration.
3. **Running DevOps Environment:** Use Docker tools to build and run containerized service environments defined in `M4A-DevopsI`.
